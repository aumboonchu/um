# เพิ่มสินค้าจากภาพหน้าจอ Makro Pro

วันที่: 28 ตุลาคม 2026

## สิ่งที่เพิ่ม

- ใช้หน้าจอ Add Purchase → ภาพหน้าสินค้า ร่วมกับภาพ Big C ได้ ไม่ต้องส่งลิงก์หรือเชื่อมบัญชี Makro Pro
- ระบุการรองรับ Makro Pro ในหน้าเว็บและแนวทางอ่านภาพของ AI
- เก็บชื่อสินค้าตามภาษาบนภาพ แบรนด์ และขนาดบรรจุรวมจำนวนชิ้น เช่น `24.6 g x 12`
- อ่านราคาอ้างอิงต่อหน่วยขาย/แพ็ก ไม่ใช้ราคาต่อชิ้น ราคาขีดฆ่า คูปอง แต้ม หรือเปอร์เซ็นต์ลดราคา
- แยก Code ของร้านออกจาก UPC/EAN/GTIN หากไม่มีบาร์โค้ดให้เว้นว่าง หรือใช้กล้องสแกนสินค้าจริง
- คงขั้นตอนตรวจแก้ข้อมูลและติ๊กยืนยันก่อนสร้าง SKU พร้อมป้องกันคำขอซ้ำด้วย UUID เดิม
- สินค้าขายเป็นแพ็ก: จำนวนซื้อ 1 หมายถึง 1 แพ็ก ไม่ใช่จำนวนชิ้นในแพ็ก

## ผลทดสอบภาพที่ผู้ใช้แนบ

ทดสอบด้วย Cloudflare AI จริงผ่านฟังก์ชันเดียวกับแอป 2 ครั้ง ได้ข้อมูลตรงกัน:

| ข้อมูล | ผลอ่าน |
| --- | --- |
| ชื่อ | OREO Sandwich Cookies with Vanilla Flavored Cream |
| แบรนด์ | OREO |
| ขนาดบรรจุ | 24.6 g x 12 |
| ราคาอ้างอิง | 45.00 บาทต่อแพ็ก (`4500` สตางค์) |
| Code ร้าน | 197584 |
| UPC | ว่าง (`null`) |

ไม่เลือก 3.75 บาทต่อชิ้น, 49.50 บาทราคาขีดฆ่า, 9% หรือแต้มในแบนเนอร์

## การตรวจสอบ

- Web tests: 183 ผ่าน
- API tests: 155 ผ่าน รวมทั้งหมด 338
- Typecheck และ frontend build ผ่าน
- Worker staging dry-run ผ่าน
- ทดสอบเส้นทาง extract → confirm → retry กับ D1 จำลองบนเครื่อง:
  - หลังอ่านภาพ จำนวนสินค้าไม่เพิ่ม
  - หลังยืนยัน จำนวนสินค้าเพิ่มเพียง 1
  - ส่ง UUID เดิมซ้ำ ได้ SKU เดิม จำนวนสินค้าไม่เพิ่มอีก
  - ไม่สร้างรายการซื้อระหว่างนำเข้าสินค้า
- ไม่สร้างข้อมูลทดสอบใน D1 staging ของผู้ใช้ และไม่แตะ production
- ไม่ต้องเปลี่ยน schema หรือทำ migration เพิ่ม
- การควบคุมเบราว์เซอร์ถูกปิดใน Work settings ระหว่างงานนี้ จึงยังไม่ได้ตรวจหน้าจอ/อัปโหลดผ่าน UI รอบนี้ และยังไม่ได้ทดสอบบน iPhone จริง

## ขอบเขตและข้อจำกัด

- AI อาจอ่านผิด ผู้ใช้ต้องตรวจชื่อ ขนาด ราคา และรหัสก่อนยืนยัน
- อ้างอิงราคาในภาพ ไม่รับประกันราคาปัจจุบัน และไม่ใช่การสั่งซื้อที่ Makro
- เก็บภาพนำเข้าเป็น `user_image` แบบเดิม ไม่อ้างว่าเป็นข้อมูลยืนยันจาก API ของ Makro หรือ Big C
- Code ร้านเก็บในใบรับการนำเข้าของบัญชี ไม่ใช้จับคู่สินค้าข้ามร้าน และไม่ทำเป็นบาร์โค้ด
- ไม่เก็บภาพต้นฉบับใน D1 หรือเพิ่มไฟล์ภาพผู้ใช้ลง GitHub; ภาพถูกส่งให้ Cloudflare AI อ่านตามขั้นตอนเดิม
- ใช้โมเดล/โควต้าเดิม ไม่มีการเปิดแผนเสียเงินหรือเพิ่มผู้ให้บริการ
- หน้าเว็บต้องใช้เวอร์ชันล่าสุด หากยังเห็นข้อความเก่าให้รีเฟรช

## วิธีใช้งาน

1. แคปหน้าสินค้าในแอป Makro Pro ให้เห็นชื่อ ขนาด และราคา
2. เปิด SmartCart → Add Purchase → ภาพหน้าสินค้า → เลือกภาพ → อ่านข้อมูลจากภาพ
3. ตรวจแก้ข้อมูล ติ๊กยืนยัน และกดบันทึกสินค้าเป็น SKU
4. หากต้องการบันทึกรายการซื้อ ค่อยกรอกราคาที่ซื้อจริง จำนวนแพ็ก ร้าน และบันทึกรายการซื้อแยกต่างหาก
