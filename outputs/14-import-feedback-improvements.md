# SmartCart — ปรับปรุงการแจ้งผล Add Purchase

วันที่: 25 ตุลาคม 2026

## ผลจากภาพที่แจ้ง

รายการในภาพ **ยังไม่ได้เพิ่มสินค้า** เนื่องจาก Big C ปฏิเสธการอ่านข้อมูล (`BIGC_BLOCKED`) ข้อความเดิมเป็นตัวอักษรสีเทาอยู่ใต้คำอธิบาย ทำให้มองไม่เห็นผลชัดเจน

## สิ่งที่ปรับ

- แสดงกรอบสถานะติดใต้ปุ่ม ก่อนคำอธิบาย พร้อมข้อความและสัญลักษณ์ ไม่ใช้สีอย่างเดียว
- กำลังนำเข้า: แสดงว่ากำลังตรวจสอบ/บันทึก และยังไม่ยืนยันผล ป้องกันการส่งซ้อน
- สำเร็จ: แสดงชื่อสินค้าและ SKU หลัง API ยืนยันข้อมูลครบเท่านั้น ลิงก์เดิมใช้ SKU เดิม
- ถูกบล็อก/ลิงก์ไม่ถูกต้อง: กรอบแดง **ยังไม่ได้เพิ่มสินค้า** พร้อมเหตุผลและทางเลือกแก้ไขลิงก์หรือใช้ UPC / เพิ่มเอง
- เน็ตหลุด/รอเกิน 15 วินาที/คำตอบไม่สมบูรณ์: แจ้ง **ยังยืนยันผลการเพิ่มไม่ได้** เพราะคำขออาจบันทึกฝั่งเซิร์ฟเวอร์แล้ว ให้ตรวจสอบด้วยลิงก์เดิม ไม่กล่าวว่าสำเร็จหรือไม่สำเร็จโดยไม่มีหลักฐาน
- แยกขั้นตอน “เพิ่มสินค้าเป็น SKU” กับ “บันทึกรายการซื้อ” ชัดเจน การนำเข้า SKU อย่างเดียวยังไม่ใช่รายการซื้อ และยังไม่ปรากฏในสินค้าของฉันที่อ้างอิงประวัติซื้อ
- มือถือ: ช่องลิงก์และปุ่มแยกแถวเต็มความกว้าง มี live region และเลื่อน/โฟกัสไปยังผลเมื่อเสร็จ เคารพ reduced motion
- เคลียร์ผลเก่าเมื่อเปลี่ยนลิงก์ และไม่คืนผลคำขอเก่าหลังออกจากระบบ
- ความล้มเหลวของ cache ในเครื่องไม่เปลี่ยนผลสำเร็จที่ D1 ยืนยันแล้ว

## ขอบเขต

ปรับเฉพาะ frontend ไม่เปลี่ยน API, schema, Google OAuth หรือข้อมูล D1 และไม่เปิดบริการเสียเงิน การบล็อกจาก Big C ยังไม่ได้ถูกแก้ไข การปรับครั้งนี้ทำให้ผู้ใช้เห็นผลจริงชัดเจนขึ้น ไม่ใช่การรับประกันว่านำเข้าจาก Big C ได้ทุกลิงก์

## การตรวจสอบ

- Web typecheck: ผ่าน
- Web tests: 55/55 ผ่าน (40 import helper, 9 feedback markup, 6 offline เดิม)
- Production frontend build: ผ่าน
- ตรวจ UI component ด้วยข้อมูลจำลองที่ไม่เขียน API/D1 บน viewport 390 และ 320 พิกเซล: ข้อความไม่ล้นแนวนอน และแยก success/error/uncertain ได้
- หน้าทดสอบและ API fixture เป็น local-only ไม่รวมในการเผยแพร่ และไม่ใช่หลักฐานว่าสินค้าจริงถูกนำเข้าแล้ว
