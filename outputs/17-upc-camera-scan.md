# SmartCart — สแกน UPC / EAN ด้วยกล้อง

## สิ่งที่เปลี่ยน

- เพิ่มปุ่ม **สแกนบาร์โค้ดด้วยกล้อง** ใต้ช่อง UPC ในหน้าตรวจข้อมูลจากภาพ และหน้า UPC / เพิ่มเอง
- ขอใช้เฉพาะกล้อง ไม่ขอไมโครโฟน เลือกกล้องหลังเป็นค่าแนะนำ (`facingMode: environment` แบบ ideal)
- อ่าน EAN-13, EAN-8 และ UPC-A ด้วย ZXing บนเบราว์เซอร์ ไม่ส่งภาพกล้องไป API/AI และไม่เก็บภาพ
- ตรวจ checksum และอ่านรหัสตรงกันสองครั้งก่อนเติมช่อง รักษาเลขศูนย์นำหน้า ไม่รับ QR, รหัสร้าน หรือเลขที่ตรวจไม่ผ่าน
- เติมเฉพาะ UPC ไม่ค้นหา/บันทึกสินค้า/ยืนยันข้อมูลให้อัตโนมัติ ในหน้าตรวจข้อมูลจากภาพจะยกเลิกเครื่องหมายยืนยันเดิม ให้ผู้ใช้ตรวจรหัสที่เติมก่อนบันทึก
- ปิดกล้องเมื่ออ่านสำเร็จ ยกเลิก สลับแท็บ/ออกจากหน้า เปลี่ยนโหมด หรือฟอร์มถูกล็อก; หยุดหลัง 60 วินาทีหากยังอ่านไม่ได้
- จัดการการอนุญาตที่ตอบกลับช้า: หากยกเลิกไปก่อนแล้วจึงได้รับ stream จะปิด tracks ทันที ไม่เริ่มอ่านต่อ
- ไม่อนุญาตกล้อง/ไม่มีกล้อง/กล้องถูกใช้งาน/โหลดตัวอ่านไม่สำเร็จ มีข้อความภาษาไทย และยังพิมพ์ UPC เองได้
- โหลดตัวอ่านเมื่อกดสแกนเท่านั้น ไม่เพิ่มการโหลดตัวอ่านทั้งหมดในหน้าแรก ไม่มีบริการเสียเงินเพิ่ม และไม่เปลี่ยน API/D1

## วิธีใช้บน iPhone

เปิด [SmartCart](https://aumboonchu.github.io/um/) ใน Safari → ช่อง UPC → สแกนบาร์โค้ดด้วยกล้อง → อนุญาตกล้องเมื่อเบราว์เซอร์ถาม → เล็งให้เห็นเส้นครบทั้งสองด้านและถือให้นิ่ง → ตรวจรหัสที่เติมก่อนค้นหาหรือยืนยันสินค้า

หากเปิดผ่านเบราว์เซอร์ในแอปแล้วเปิดกล้องไม่ได้ ให้ลองเปิดผ่าน Safari โดยตรง สามารถยกเลิกและพิมพ์รหัสเองได้เสมอ

## ผลตรวจสอบ

- TypeScript เว็บผ่าน; ชุดทดสอบเว็บ 125/125 (เพิ่ม scanner 27 รายการ) ผ่าน
- Build ผ่าน แยกตัวอ่านบาร์โค้ดเป็น lazy chunks
- ถอดรหัสภาพ EAN-13 ทดสอบจริงผ่าน ZXing core ไม่ได้ทดสอบแค่กรอกตัวเลขสำเร็จรูป
- ทดสอบ UI ด้วย canvas video stream จำลองใน Chrome: ตัวอ่านจริงอ่าน EAN-13 → เติม `8851959129012` → กล้องจำลองปิด (`readyState: ended`)
- ทดสอบยกเลิกและจำลองไม่อนุญาตกล้องใน UI: รหัสเดิมไม่เปลี่ยน มีข้อความอธิบาย
- ขนาด 390 × 844 px ไม่พบ horizontal overflow; คืนค่าขนาดหน้าจอหลังทดสอบแล้ว
- ไม่ได้เปิดกล้องจริงบนคอมพิวเตอร์หรือทดสอบกล้อง Safari/Home Screen ของ iPhone จริง จึงยังไม่รับรองผลบนทุกอุปกรณ์
- ตรวจ dependency lock แล้ว เพิ่มเฉพาะ @zxing/browser, @zxing/library, @zxing/text-encoding และ ts-custom-error ไม่มีแพ็กเกจเดิมถูกอัปเกรดหรือลบ
- `npm audit --omit=dev` ไม่พบรายงานใน dependencies ตัวอ่านใหม่ แต่พบคำเตือน moderate เดิมใน Hono ฝั่ง API (ส่วน JSX boundary / serveStatic) ไม่แก้หรืออัปเกรด backend นอกขอบเขตงานนี้
- ไฟล์ harness/สตรีมจำลองเป็นการทดสอบในเครื่องเท่านั้น ลบก่อนสร้างและเผยแพร่ ไม่รวมในเว็บจริง

อ้างอิง: [ZXing Browser](https://github.com/zxing-js/browser), [getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)
