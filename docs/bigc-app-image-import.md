# Big C app — เพิ่มสินค้าจากภาพ

ใช้เมนู **เพิ่มจากรูป** เดิม รองรับภาพหน้าสินค้าจากแอป Big C โดยไม่ต้องมี URL หรือแถบเบราว์เซอร์ และยังรองรับเว็บ Big C / แอป Makro Pro

## ขั้นตอน

1. แคปหน้าสินค้าให้เห็นชื่อ ขนาด และราคา แล้วครอปข้อมูลส่วนตัวออก
2. เลือกภาพ → อ่านข้อมูลจากภาพ (ต้องเข้าสู่ระบบและออนไลน์)
3. ตรวจหรือแก้ข้อมูล แล้วติ๊กยืนยัน → บันทึกและใส่ราคา
4. ใส่จำนวนและราคาซื้อจริง → เพิ่มเข้ารอบ
5. ยืนยันชำระแล้วเมื่อจบรอบ จึงบันทึกเป็นรายงานยอดซื้อ

ภาพส่งให้ Cloudflare AI อ่าน แต่ SmartCart ไม่เก็บไฟล์ภาพต้นฉบับลง D1 การอ่านภาพเพียงอย่างเดียวไม่สร้างสินค้า ไม่สร้างรายการซื้อ และไม่ชำระเงินจริง

## กรณีตัวอย่างจากภาพที่ผู้ใช้ส่ง

| ข้อมูล | ค่าที่คาดหวัง |
| --- | --- |
| ชื่อ | คริสตัล น้ำดื่ม 600 มล. |
| แบรนด์ | คริสตัล |
| ขนาด | 600 มล. |
| ราคาอ้างอิง | 6 บาท / ขวด (`sourcePriceMinor: 600`) |
| รหัสร้าน | 13627 (`retailerCode`) |
| UPC / EAN | ว่าง — ภาพไม่แสดงบาร์โค้ด |

เลข อย. `14-1-22146-2-0013` ไม่ใช่รหัสร้านหรือบาร์โค้ด ตัวนับภาพ `1/5` ไม่ใช่จำนวนชิ้นต่อแพ็ก ตัวอ่านได้รับคำสั่งแยกข้อมูลเหล่านี้และไม่เดาค่าที่ไม่ปรากฏ ส่วน parser ตัดรูปแบบเลข อย. ที่ชัดเจนออกจากรหัสร้านด้วย

ค่าข้างต้นเป็นข้อมูลคาดหวังที่ถอดจากภาพเพื่อทดสอบ ไม่ใช่การอ้างผล OCR จริง ทุกครั้งยังต้องตรวจและยืนยันก่อนสร้าง SKU ใช้ UUID เดิมเมื่อส่งซ้ำ และแยกรหัสร้านออกจาก UPC เสมอ รูปต้นฉบับของผู้ใช้ไม่ถูกนำเข้า repository

## ขอบเขต

- ใช้ API, Workers AI binding, D1 schema และโควตาเดิม ไม่เพิ่มบริการหรือแพ็กเกจเสียเงิน
- ไม่บันทึกสินค้าตัวอย่างหรือรายการซื้อเข้าฐานข้อมูลของผู้ใช้โดยอัตโนมัติ
- การทดสอบอัตโนมัติใช้ผลอ่านภาพจำลองและ D1 ในเครื่อง ไม่ยืนยันความแม่นยำของ AI บนภาพจริงหรือการใช้งาน iPhone จริง
- ไม่มี database migration ในการเปลี่ยนแปลงนี้
