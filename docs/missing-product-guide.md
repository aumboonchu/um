# วิธีเพิ่มสินค้าเมื่อค้นไม่พบ

เพิ่มหน้าคู่มือใน journey เดิมของ SmartCart สำหรับมือถือ เปิดด้วยปุ่ม “วิธีเพิ่มสินค้า” บนหน้าเพิ่มสินค้าที่สแกนแล้วไม่พบ ไม่บังคับอ่านก่อนเพิ่มและไม่เพิ่มเมนูหลักใหม่

คู่มือมีสามขั้นตอนสั้น ๆ: จับภาพหน้าสินค้า Big C / Makro Pro ให้เห็นชื่อ ขนาด ราคา (ตัดข้อมูลส่วนตัวออก) หรือกรอกชื่อเอง; ตรวจข้อมูลและบาร์โค้ดก่อนบันทึก โดยรหัสร้านไม่ใช่ UPC / EAN; ใส่จำนวนกับราคาที่ซื้อจริงแล้วเพิ่มเข้ารอบ การเพิ่มสินค้าอย่างเดียวยังไม่บันทึกรายการซื้อ

ปุ่ม “เพิ่มจากรูป” ใช้ ImageImport เดิมพร้อมบาร์โค้ดที่สแกน ปุ่ม “กรอกข้อมูลเอง” และปุ่มกลับคืนหน้าเพิ่มสินค้าโดยรักษาชื่อ แบรนด์ ขนาด และบาร์โค้ดเดิม ไม่เพิ่มสินค้า ไม่สร้างรายการซื้อ ไม่เปลี่ยนตะกร้าจนกว่าจะยืนยันตาม flow เดิม

ใช้ React / TypeScript / CSS และ asset เดิม ไม่มี dependency, API, D1 migration, auth หรือ DNS ใหม่ หน้าอ่านได้เมื่อแอปที่ตรวจบัญชีแล้วออฟไลน์ แต่ไม่อนุญาตสร้างสินค้าออฟไลน์; cache miss ใช้ข้อความ “ยังไม่มีสินค้านี้ในเครื่อง” ไม่สรุปแทนฐานข้อมูลทั้งหมด

แนวทางที่เลือก: หน้าย่อยใน ShoppingJourney เพราะรักษาบริบท UPC และฟอร์มเดิมได้ตรงที่สุด การใส่คำอธิบายยาวในฟอร์มขัดกับ less-is-more; คู่มือภายนอกแยกเว็บทำให้กลับไปทำรายการยากขึ้น ทั้งหมดเป็นรายละเอียดการออกแบบของผู้พัฒนาเพื่อให้ตรงคำขอ ไม่ใช่การเพิ่มขอบเขตใหม่

ตรวจด้วย DOM journey: เปิด/กลับโดยไม่เขียนข้อมูล, manual/image path พร้อม UPC, รักษาฟอร์มและตะกร้า, ออฟไลน์แล้วกลับออนไลน์, ไม่แสดงคู่มือกรณีพบสินค้า/ระบบค้นหาขัดข้อง; ใช้ heading focus, ปุ่มอย่างน้อย 48 px และไม่มี horizontal overflow ที่ 320/390/440 px
