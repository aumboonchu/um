# รูปสินค้าแบบครอปและแตะขยาย

## ใช้งาน

เพิ่มจากรูป → เลือกภาพ Big C / Makro Pro → อ่านข้อมูล → ครอปรูปสินค้า → ลากกรอบให้เหลือเฉพาะตัวสินค้า → ใช้รูปที่ครอป → ตรวจข้อมูลและบันทึก

AI ในคำขอเดิมแนะนำกรอบได้ แต่ยังต้องตรวจและกดยืนยัน รูปหน้าจอเต็มใช้เพื่ออ่านข้อความเท่านั้น ไม่ถูกบันทึกเป็นรูปสินค้า หากไม่ต้องการรูป ให้เลือก “ไม่ใส่รูปสินค้า” อย่างชัดเจน

รูปเล็กในรายการสินค้า รอบซื้อ รายละเอียดสินค้า และ admin แตะเพื่อดูรูปใหญ่ได้ หน้าขยายแสดงรูปเดียว ไม่มีราคา/ข้อความจากหน้าจอต้นฉบับ มีปุ่มปิด แตะพื้นหลังหรือกด Escape เพื่อกลับ ไม่เผลอเปิดการแก้ไขรายการเมื่อแตะรูป

## สินค้าเดิมที่ไม่มีรูป

ภาพต้นฉบับของการนำเข้ารุ่นเก่าไม่ได้เก็บไว้ จึงไม่สามารถครอปย้อนหลังอัตโนมัติได้ เข้า สินค้า → ผู้ดูแลระบบ → เลือกสินค้า → เลือกรูปสินค้า / เปลี่ยนรูปสินค้า → ครอป → ใช้รูปที่ครอป

เป็นการใส่รูปให้ SKU เดิม ไม่สร้างสินค้าใหม่ ไม่เปลี่ยนบาร์โค้ด รายละเอียดที่ตั้งไว้ ยอดซื้อ หรือใบสรุปที่ชำระแล้ว

## ขอบเขตและการเก็บข้อมูล

- ทำ crop ด้วย canvas บนอุปกรณ์ แยกจากภาพที่ใช้ OCR ไม่ใช้ AI วาดสินค้าใหม่
- เก็บเฉพาะ JPEG ที่ยืนยันแล้ว ไม่เก็บภาพต้นฉบับ EXIF/XMP หรือข้อความ comment metadata
- รูปละไม่เกิน 128 KiB ด้านยาวไม่เกิน 640 px ด้านสั้นอย่างน้อย 16 px รักษาสัดส่วน ไม่ยืด crop ที่แคบเกินไป
- ใช้ตาราง `product_images` ใน D1 เดิม หนึ่งรูปปัจจุบันต่อสินค้า ไม่มี R2 หรือบริการเสียเงินใหม่ พื้นที่และ quota ของแผนฟรียังมีขีดจำกัด
- รูปที่ยืนยันแล้วเป็นรูปสินค้ากลาง แสดงผ่าน URL รูปแบบ product ID + SHA-256 ไม่ใส่ชื่อบัญชี อีเมล หรือ token ใน URL รูปนี้ไม่ใช่พื้นที่เก็บภาพส่วนตัว
- นำเข้าปกติเติมรูปได้เฉพาะสินค้าที่ยังไม่มีรูป ไม่ทับรูปเดิมของระบบ การเปลี่ยนรูปสินค้าที่มีอยู่ต้องผ่านสิทธิ์ admin
- คำขอแก้รูป admin ตรวจ Google session, elevated token, Origin, account ID, UUID และ revision มี audit ก่อน/หลังใน transaction เดียว
- ก่อนส่งเก็บเฉพาะ crop ขนาดเล็กกับ UUID ใน storage ที่แยกบัญชี หากเก็บไม่ได้จะไม่ส่งคำขอที่เสี่ยงตรวจผลไม่ได้
- คำตอบหาย/เน็ตหลุดเก็บ UUID เดิมไว้ ไม่อ้างว่าสำเร็จจนตรวจ receipt ได้ ไม่มีการส่งเป็นสินค้า/คำขอใหม่โดยพลการ
- รูปบนรายงานเป็นภาพปัจจุบันของแค็ตตาล็อกประกอบรายการเท่านั้น ชื่อ ขนาด และยอดเงินใน snapshot รอบที่ชำระแล้วยังเป็นข้อมูลเดิม ไม่เขียนย้อนหลัง
- ภาพต้นฉบับหรือ crop ที่ยังไม่กดยืนยันไม่ได้เก็บถาวร หากออกจากหน้าหรือสิทธิ์ admin หมดอายุก่อนยืนยัน อาจต้องเลือกรูปใหม่ การกู้รูปหลังหมดสิทธิ์ครอบคลุมเฉพาะคำขอ crop ที่ยืนยันและบันทึก UUID ไว้แล้ว
- รุ่นนี้ไม่รับประกันว่ารูปที่เคยเปิดแล้วจะดูได้ขณะออฟไลน์ หากโหลดรูปไม่ได้จะกลับไปใช้ไอคอนเดิม โดยไม่กระทบข้อมูลซื้อที่เก็บไว้ในเครื่อง

## การตรวจสอบ

ทดสอบ crop coordinates, pointer/range controls, canvas output bounds, request/receipt, pending recovery, admin permissions, atomic rollback และภาพของรายงานโดยไม่แก้ snapshot

ตรวจเบราว์เซอร์จริงที่ viewport 430×932 ด้วยภาพทดสอบสังเคราะห์ในเครื่อง: กรอบตัดแถบเมนู ราคา ชื่อ และปุ่มซื้อออก เหลือภาพผลิตภัณฑ์; ยืนยัน crop แสดง thumbnail แล้วแตะขยายและปิดกลับได้ ไม่ส่งรูปทดสอบขึ้นฐานข้อมูลจริง ไม่อ้างว่าได้ทดสอบบน iPhone จริงหรือทดสอบความแม่นของ AI กับรูปผู้ใช้จริงจากการตรวจนี้
